# College Placement Information Portal

## Project Overview
A web-based College Placement Information Portal built with modern web technologies:
- **Bootstrap 5**: Responsive layout, cards, navigation bar, and modals.
- **AngularJS**: Dynamic data binding, search filtering, drive details modal.
- **jQuery & AJAX**: Form validation, dynamic DOM updates, XML parsing demonstration.
- **GitHub & GitHub Pages**: Version control, repository structure, and live deployment.

## Project Structure
```text
college-placement-portal/
├── index.html        # Main application file containing single-page app structure
└── README.md         # Documentation & deployment guide
```

## How to Run on Laptop
1. Extract the contents of `college-placement-portal.zip`.
2. Open `index.html` directly in any standard browser (Google Chrome, Microsoft Edge, Firefox, Safari).

## Steps to Deploy on GitHub Pages
1. Go to [GitHub](https://github.com) and create a new public repository named `college-placement-portal`.
2. Upload `index.html` and `README.md` to your repository.
3. In repository **Settings** -> **Pages**:
   - Set Source to `Deploy from a branch`.
   - Set Branch to `main` (or `master`) and folder to `/ (root)`.
   - Click **Save**.
4. Your site will be published at `https://<your-github-username>.github.io/college-placement-portal/`.
